# Pistas de audio

El reproductor (`app-audio-player`, en el header) busca estos archivos acá:

```
fantasy-ambient.mp3
magic-ambient.mp3
anime-ambient.mp3
scifi-ambient.mp3
horror-ambient.mp3
```

No vienen incluidos: no puedo garantizar que un link a un CDN externo siga
funcionando o tenga la licencia correcta. Sin el archivo, el botón sigue ahí
pero no rompe nada — simplemente no suena hasta que pongas el mp3.

## Dónde conseguirlas gratis

- **https://pixabay.com/music/** — licencia Pixabay, sin atribución requerida.
- **https://freesound.org/** — revisá la licencia de cada pista, varía.
- **https://itch.io/game-assets/free/tag-music** — muchos packs CC0.

# Pistas de audio

Este reproductor busca estos 5 archivos acá adentro:

```
fantasy-ambient.mp3
magic-ambient.mp3
anime-ambient.mp3
scifi-ambient.mp3
horror-ambient.mp3
```

No vienen incluidos: no puedo garantizar que un link a un CDN externo siga
funcionando o tenga la licencia correcta, así que en vez de arriesgar un link
roto, el reproductor simplemente detecta que falta el archivo y muestra
"sin pista" sin romper nada.

## Dónde conseguirlas gratis

- **https://pixabay.com/music/** — licencia Pixabay, no exige atribución. Buscá "fantasy ambient" o "dark ambient".
- **https://freesound.org/** — revisá la licencia de cada pista individual, varía entre CC0 y CC-BY.
- **https://itch.io/game-assets/free/tag-music** — muchos packs CC0 pensados para juegos.

Bajá el mp3, renombralo como corresponde de la lista de arriba, y ponelo en
esta carpeta. El reproductor lo detecta solo, sin tocar código.
